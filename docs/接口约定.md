# 接口约定

视频画面（Claude）和后端数据（GPT）两边只通过下面这些文件对接。改格式前先改本文件，再同步更新样例和测试。

| 文件 | 谁写 | 谁读 | 格式定义 / 样例 |
|---|---|---|---|
| `data/topics.json` `structures.json` `hooks.json` `tags.json` `hot.json` | 后端 | agent 写剧本时 | 各文件本身；测试 `tests/test_pick_topic.py` `test_digest.py` `test_hot.py` |
| `data/research/*.json` | 后端（`research/collect.py`） | 后端（`research/digest.py`） | `tests/fixtures/research/` |
| `out/<编号>/script.json` | agent（写剧本） | 两边：后端做检查和查重，视频端渲染 | `tests/fixtures/script_ok.json`，规则 `pipeline/script_check.py` |
| `out/<编号>/visual.js` | agent（视频端，画面档） | 视频端（`pipeline/compile_script.py` 编进页面，`engine/engine.js` 按场景的 `visual` 调用） | `window.VISUALS = {场景名: {bg, build, init?, anim, sfx?}, …, outro?}`，写法见 `docs/画面档写法.md`；范例 `out/2026-11-17-s*-a/visual.js`；测试 `tests/test_preview.py` |
| `assets/footage/s<步骤>/pack.json` | 录屏工具 | 视频端（`--footage auto`）、后端（实测数字核对） | `pipeline/pack.py` 的 `REQUIRED` |
| `out/<编号>/publish.json` | 视频端（`make.py`） | 用户、`tools/refill.py` | `pipeline/make.py` |
| `data/history.json` | 视频端（出片成功后追加） | 后端（选题、查重、数据反馈） | `pipeline/pick_topic.py` 的 `load_history` |
| `data/metrics.csv` | 用户手填 | 后端（`tools/report.py`） | 表头：编号,播放,完播率,点赞,收藏,涨粉 |
