# 电商自动化 · 7 条视频选题与 skill 对接清单

2026-11-17 · 韬行科技

## 这份清单是干什么的

我们已经为下面 7 个选题各做好一条 40 秒左右的推广短视频，准备发抖音和视频号。视频里**向观众承诺了每个 skill 能做什么**，所以 skill 要按这里写的功能来做，做出来要和视频说的一致。

其中 2 个 skill 已经有了，另外 5 个视频结尾说的是"正在做，上线免费送"。观众会在评论区留关键词等着领，**所以这 5 个需要尽快做出来**。

skill 做好后，我们会自动跑一遍并录屏，替换视频里现在的"示意"画面，再出一版带实测数据的视频。

## 所有 skill 的共同要求

1. **能在测试环境跑通**：测试店铺、测试商品或演示数据都行。我们要自动录屏，不能碰真实客户和真实订单。
2. **会改变真实状态的动作一律停下来让人确认**，例如提交、发布、改价、报名、给客户发消息。几条视频都把"最后由你拍板"当成卖点。
3. **记录可量化的结果**：处理了多少条、用了多少秒。视频里自动化一侧的数字只能用实测值，现在一律没写。
4. **过程看得见**：执行时有清楚的进度或逐项变化，方便录屏剪成 3–5 秒的高光片段。
5. 附一份简短的使用说明，方便评论区领取的用户上手。

## A 商品上架（已有，拼多多发布助手）

- **视频里讲的痛点**：一千个商品要一个个手动填，几个人要忙好几天。
- **视频承诺的功能**：
  - 自动打开后台、进入发布页，全程不用动手；
  - 按商品资料逐项填写标题、类目、规格、价格、库存；
  - 每填一项核对一项。
- **视频最后揭晓的关键点**：提交之前停下，等用户亲自确认。
- **用上它的三步**：准备好商品资料 → 让助手连上后台 → 提交前亲自确认。
- **需要补的**：一次批量上架的实测数据（多少个商品、用时多少），用来替换视频里的估算对比。

## B 商品资料检查（已有）

- **视频里讲的痛点**：几千行商品表里缺规格、价格填错、编码重复，上架后才发现，全店跟着改。
- **视频承诺的功能**：
  - 把表格放进去，自动逐行检查；
  - 标出缺项、重复编码、异常价格和库存。
- **视频最后揭晓的关键点**：先统一格式再检查，所以不会漏。**skill 里要有"统一格式"这一步，并且能展示出来。**
- **需要补的**：演示数据的检查实测（多少行、用时多少、查出几类问题）。

## C 营销推广（待开发）

- **视频里讲的痛点**：平台活动太多，常常截止前一天才想起报名；选关键词靠猜；花了钱说不清效果。
- **视频承诺的功能**：
  - 自动整理各平台可报名的活动，生成清单（含截止时间）；
  - 自动测算关键词；
  - 自动汇总投放数据。
- **视频最后揭晓的关键点**：各平台数据口径不统一，自动化之前要先对齐。**skill 要有统一口径的处理，比如字段映射和统一的指标定义。**
- **安全边界**：只整理和提醒，不自动报名、不自动投放花钱。

## D 数据复盘（待开发）

- **视频里讲的痛点**：每周复盘要去五个后台挨个导表、对数、写报告，一个下午就没了（视频里人工耗时是估算的 4 小时）。
- **视频承诺的三个功能**：
  - 多店铺数据自动汇总；
  - 多平台数据放进同一张表，口径先对齐；
  - 自动生成复盘报告。
- **视频最后揭晓的关键点**：最省时间的是"多平台数据自动放进一张表、口径先对齐，复盘直接看结论"。**这一项必须做扎实。**
- **需要补的**：一次完整复盘的实测用时。

## E 素材生产（待开发）

- **视频里讲的痛点**：一款新品的主图、详情、短视频加起来十几张图，美工排期排不过来，上新一拖再拖。
- **视频承诺的功能**：
  - 放进商品资料，自动生成图文、详情页、短视频的初稿；
  - 可以选风格；
  - 能成批生成。
- **用上它的三步**：放进商品资料 → 选好风格 → 发布前你亲自挑一遍。
- **视频最后揭晓的关键点**：发布前由人挑选，好的留下，不满意的一键让它重做。**必须有"挑选和重做"的环节，不能直接发布。**
- **注意**：生成的图片和视频要能商用，不能用来源不明的素材。

## F 客服对接（待开发）

- **视频里讲的痛点**：客服早上一开电脑就有 99+ 条消息；每条都要切到后台查订单、对库存；最怕漏回售后。
- **视频承诺的三个功能**：
  - 订单和库存自动同步，客服打开就能看到，不用切后台；
  - 常见问题自动整理；
  - 售后信息自动汇总。
- **视频最后揭晓的关键点**：售后自动汇总成一张清单，哪条回了、哪条没回一眼看清。**这张"售后清单"是核心界面。**
- **安全边界**：不自动给客户发消息，只做整理和提醒。演示用虚构的订单和客户。

## G 选品控价（待开发）

- **视频里讲的痛点**：竞品偷偷降价，靠一个个翻页面，常常第二天才发现；选品靠感觉，比价靠手翻。
- **视频承诺的功能**：
  - 行业和单品数据自动汇总；
  - 竞品价格自动对比；
  - 价格异常自动提醒。
- **视频最后揭晓的关键点**：不要让系统自动跟价，乱改容易亏。提醒交给系统，改不改价由人决定。**skill 只提醒、不自动改价，这一点是卖点，不能做成自动跟价。**
- **需要补的**：从竞品改价到收到提醒的实测间隔。

## 做好后请交给我们

1. skill 的文件夹路径或安装方式。
2. 测试环境（测试店铺、账号或演示数据）怎么用。
3. 哪一步会停下来等人确认，按钮叫什么。
4. 一次实测记录：处理了多少条、用了多少秒。

有了这些，我们就能自动录屏、剪高光，把视频里的"示意"画面换成真实画面，再出带实测数据的新版。
