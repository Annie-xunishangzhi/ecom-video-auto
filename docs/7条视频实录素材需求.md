# 7 条视频的实录素材需求

2026-11-17 · 韬行科技 · 配合《电商自动化选题清单》使用

## 先说明

每条视频里留了 1–2 个"实录位"，用来放 skill 真实运行的画面。没有实录时，这里显示的是"示意"占位画面。实录位只占 3–5 秒，我们会从录屏里截出对应片段，最多加速 4 倍。所以**录屏本身要完整、正常速度地录一整遍**，不用自己剪。

| # | 视频 | 实录位 | 现状 |
|---|---|---|---|
| A | 商品上架 | 2 个（开头钩子 + 中段） | 用的是旧录屏，需要重录一版并带实测数据 |
| B | 商品资料检查 | 1 个（中段） | ✅ 已完成实录（10 行演示数据，检查耗时 0.94 秒） |
| C | 营销推广 | 1 个（中段） | 等 skill 做好后录 |
| D | 数据复盘 | 1 个（中段） | 等 skill 做好后录 |
| E | 素材生产 | 1 个（中段） | 等 skill 做好后录 |
| F | 客服对接 | 1 个（中段） | 等 skill 做好后录 |
| G | 选品控价 | 2 个（开头钩子 + 中段） | 等 skill 做好后录 |

## 所有录屏的共同要求

1. **只用测试环境**：测试店铺、测试账号、虚构的商品、订单和客户。画面里不能出现真实店铺名、账号、手机号、客户昵称和地址。实在避不开的，告诉我们它在画面的哪个位置，我们来打码。
2. **到需要人确认的那一步就停**，比如提交、发布、改价、报名、给客户发消息。停住的画面本身也是素材，停在那里多录 3 秒。
3. **横屏、全屏录**：分辨率最好是 1920×1080，浏览器缩放 100%。关掉消息通知、弹窗和无关的标签页。
4. **从头到尾录一遍，不要剪辑**，同时把每一步的开始时间记下来（格式见文末）。
5. **记实测数据**：处理了多少条、从开始到完成用了几秒。视频里自动化一侧的数字只用这个实测值。
6. **画面要有明显变化**：逐行打勾、进度条、表单一项项被填上、清单一条条出来，这些最适合剪成高光。鼠标乱晃或长时间静止的画面用不上。

## A 商品上架（拼多多发布助手）

**实录位 1：开头钩子（约 3.6 秒）**
- 配音："看，打开后台、进发布页，全程不用你动手。"
- 要录到：助手自动打开拼多多商家后台 → 进入商品发布页 → 表单开始被自动填写。

**实录位 2：中段（约 4.3 秒）**
- 配音："第一步准备好商品资料，第二步让助手连上后台。"
- 要录到：
  - 准备好的商品资料表格被载入；
  - 助手连上后台，标题、类目、规格、价格、库存逐项被填好。

**另外需要**
- 停在"提交"按钮前、等待人工确认的画面，录 3 秒以上。
- 实测数据：一次批量上架多少个商品、总共用时多少秒。

## B 商品资料检查（已完成）

**实录位：中段（约 4 秒）**
- 配音："它是怎么做到又快又不漏的？关键只有一个动作。"
- 已录内容：载入演示数据 → 开始整理与检查 → 问题行被逐条标出。
- 如果后面要补录：最好能录到"先统一格式"这一步，因为它就是片尾揭晓的关键动作。

## C 营销推广

**实录位：中段（约 5.4 秒）**
- 配音："活动自动整理成清单，关键词自动测算，这两件都不难。"
- 要录到：
  - 各平台的活动自动汇总成一张清单，带截止时间；
  - 关键词测算结果自动出来。
- 另外最好有一个画面能看出不同平台的数据口径被统一，对应片尾"先对齐口径"。
- 注意：不点"报名"，不开投放。

## D 数据复盘

**实录位：中段（约 4.6 秒）**
- 配音："它有三个功能，其中一个最省时间，看到最后你就知道。"
- 要录到：多个店铺、多个平台的数据被自动拉取或导入，汇总进同一张表。最好能看到表格一行行、一列列被填满。
- 另外需要：
  - 最后生成复盘报告的画面；
  - 实测数据：一次完整复盘的用时。视频里人工耗时写的是估算 4 小时。

## E 素材生产

**实录位：中段（约 4.2 秒）**
- 配音："放进资料，选好风格，初稿就一批批出来了。"
- 要录到：放入商品资料 → 选择风格 → 主图、详情图、短视频初稿成批生成（缩略图一张张冒出来最好）。
- 另外需要：
  - "挑选 / 重做"环节的画面：勾选留下、点重做后重新生成，对应片尾揭晓；
  - 实测数据：一批生成了多少张、用时多少。
- 注意：演示用的商品图片要有版权，或者是我们自己的。

## F 客服对接

**实录位：中段（约 4.2 秒）**
- 配音："那它是怎么做到一条都不漏的？关键就在一个地方。"
- 要录到：订单和库存信息自动同步到客服界面，打开一个会话就能直接看到对应订单。
- 另外需要：
  - 售后汇总清单的画面，"已回 / 未回"状态清楚，这是片尾揭晓的核心界面；
  - 实测数据：清单汇总了多少条售后、用时多少。
- 注意：订单和客户全部用虚构数据，不自动给客户发消息。

## G 选品控价

**实录位 1：开头钩子（约 4.1 秒）**
- 配音："以后行业数据自动汇总，竞品价格自动对比。"
- 要录到：行业和竞品数据自动汇总，出现竞品价格对比表。

**实录位 2：中段（约 3 秒）**
- 配音："价格一有异常，它会马上提醒你。"
- 要录到：竞品价格变动后，弹出或高亮一条异常提醒。可以在测试数据里手动改一个竞品价格来触发。

**另外需要**
- 提醒出来后，"改不改价由人决定"的画面，例如提醒卡片上有"去处理"按钮，但没有自动改价。
- 实测数据：从竞品改价到收到提醒，间隔多少秒。

## 交付方式

每个 skill 交这几样，放进一个文件夹即可：

1. **录屏文件**：mp4 或 webm，未剪辑的原始文件。
2. **步骤时间**：一个 txt 文件，每行写"秒数 步骤名"，例如：
   ```
   0 打开工具
   5 载入演示数据
   12 开始检查
   13 结果出来
   ```
3. **实测数据**：处理了多少条、用时多少秒。
4. **需要打码的位置**（如果有）：截一张图圈出来即可。

收到后我们会自动剪出高光、打码，换进视频，再出带实测数据的新版。
