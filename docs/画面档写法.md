## 1. 先做分镜，再写代码

每个场景先用一句话写出"画面在演什么事"，而不是"屏幕上有哪几行字"。好的分镜都是一个**变化**：

| 配音在说 | 差的画面（PPT） | 好的画面（演出来） |
|---|---|---|
| 回访全靠记忆，事情一多就漏了 | 两行大字"事情一多 / 回访就漏了" | 通知一条条压下来、越来越快，"回访王姐"那条被挤出画面，盖上"漏了"印章 |
| 名单整理交给自动化 | 一个"名单自动整理"的卡片 | 乱序的条在卡片里自己排好序；零散记录被吸进名单逐行打勾 |
| 还有一项更省心的功能 | 一个问号 | 上锁的神秘卡在光芒里慢慢转，扫光一遍遍掠过 |
| 省下时间拿去选品和运营 | 两个图标 | 时钟指针飞转，光点流向"选品""运营"两块 |

每个场景至少两拍：**进场一拍 + 配音关键词处一拍**（用 `H.at(sc,'关键词')` 取时间点）。超过 4 秒的场景要有第三拍。

## 2. 构图

- 画布 1080×1920。关键内容放在 y 150–1460、x 60–1020；1478–1588 是字幕条，再往下是平台界面。装饰（光斑、粒子、配图）铺满整屏。
- 主体居中偏上：标题 y 170–460，主体 y 480–1300，辅助信息 1300–1440。
- 三层景深：背景（渐变 + 漂移光斑 + 网格 + 尘埃，或配图慢推）、中景（玻璃卡片、手机、图形）、前景（标题、爆开、冲击环、扫光）。
- 企鹅由引擎画：`mascot` 字段，自定 `S` `x` `f`（脚底 y）让它站在空处，不挡字；`move` 让它走位。
- 字号：主标题 110–150，卡片内 38–60，小字不低于 28。

## 3. 运动

- 进场用"推进 + 去模糊"（范例里的 `stage()`），出场轻微后撤，场景之间硬切，看起来像穿过去。自写场景默认不叠引擎色块转场。
- 文字逐字进场（`split` + `textIn`），重点词用 `outBackBig` 放大回弹，停住后加 `textWave` 微动。
- 元素错峰（间隔 0.08–0.3 秒），用弹簧（`spring`）或 `outBack`，不用线性。
- 永不停住：背景光斑按全片时间 `H.T` 漂移；卡片 `wob` 漂浮；扫描框、扫光、数据流循环；数字跳动。
- 关键时刻加冲击：`ring` 冲击环、`burst` 彩片、`flash` 闪白、印章砸下。
- 出片会做运动检查；不过就看 `motion.json` 报的时间段，给那里加一拍。

## 4. 套件 KIT（`engine/kit.js`）

每条视频都要的东西已经在 `window.KIT` 里，直接用，不要再抄一遍：

- `K.layers(id, 内容HTML)`：背景画布 + 舞台 + 特效画布三层；`K.frame(id, t, H, 背景参数, 进场参数)` 每帧开头调一次：画背景、做进出场，返回特效画布。**第三个参数一定是 H**。
- 背景参数：`{seed, hue, hue2, hue3, base:[上,中,下], grid, dust}`，每条视频换一套颜色，形成自己的气质（暮紫、深海蓝、墨绿……）。
- 进场参数：`{push, seed, beats:[秒,…]}`。`beats` 是镜头"顿一下"的时间点，放在配音重音上（`H.at(sc,'词')`），也是补"缺新动作"最直接的办法。
- `K.title(字数组, t, 开始, 'drop'|'rise'|'punch'|'slide')` 常用逐字进场；`K.I.*` 内联 SVG 图标（list check cross bell bag chart table clock search folder warn chat image lock hand gift spark）；`K.win(id, 标题, 位置)` 浏览器窗口外框（内容区 id 为 `id+'body'`）；`K.ctaBlock(id, sc, H)` 结尾的关注按钮 + 评论框打字 + 手指；`K.outro(背景参数)` 统一落版。
- 共用类名：`v-a`（绝对定位）`v-t`（大标题）`v-acc` `v-ctr` `v-glass` `v-solid` `v-pill(.dim/.hot/.light)` `v-row` `v-av` `v-tag(.ok/.warn/.bad)` `v-ok` `v-ic` `v-btn` `v-shi`（"示意"角标）`v-win` `v-stamp` `v-q` `v-input`。本片自己的类名用一个字母前缀（如 `e-`），避免和套件撞名。

## 5. 骨架

```js
(function(){
const K=window.KIT,M=()=>window.MO,{ACC,GOLD,MINT,I}=K;
const BG={seed:8,hue:[60,140,255],hue2:[255,77,26],base:['#0f1a36','#0a1226','#050912']};   // 本片的气质
document.head.insertAdjacentHTML('beforeend',`<style>.d-card{/* 本片样式，类名带前缀 */}</style>`);
const split=(id,...ks)=>ks.forEach(k=>M().split(document.getElementById(id+k)));
window.VISUALS={
 hook:{bg:'#0a1226',
  build:(sc,id,H)=>K.layers(id,`
   <div class="v-a v-t v-ctr" id="${id}hd" style="top:180px;font-size:130px">${H.fmt(sc.head)}</div>
   <div class="v-a v-glass" id="${id}card" style="left:70px;top:430px;width:940px;height:700px"></div>`),
  init:(sc,id)=>split(id,'hd'),
  anim:(sc,id,t,H)=>{const MO=M(),$=H.$;
   const k=H.at(sc,'自动')??1.5;                                   // 配音说到"自动"的时刻
   const g=K.frame(id,t,H,BG,{seed:2,beats:[k]});                   // 背景 + 进场 + 在 k 处镜头顿一下
   K.title($(id+'hd')._chars,t,0.1,'drop');
   MO.set($(id+'card'),{y:200*(1-MO.tw(t,0.2,0.5,'outBack')),o:MO.tw(t,0.2,0.2)});
   MO.ring(g,t,k,540,780,{r1:600});                                 // 特效画在 g 上
  },
  sfx:()=>[[0.1,'pop']]},
 outro:K.outro(BG),
};
})();
```

## 6. 实录

`footage` 场景有素材包时（`--footage auto`），引擎会预载帧：`H.frame(sc,t)` 取当前帧，`H.drawFrame(g,图,x,y,w,h)` 画进 canvas。把实录放在手机/浏览器外框里，外面加计时、进度、高光框。没有素材包时 `H.frame` 返回 `null`：画示意动画，并且画面上必须有"示意"二字。

实录经常是一张几乎不动的结果页（例如检查完成后的统计页），直接铺上去会被运动检查判成"缺新动作"。做法：在 canvas 里用 `drawImage` 的源矩形做镜头——先推近到关键数字、停一下、再沿表格往下摇，同时在原画面坐标上画高亮框（见 `s2-a` 的 `real` 场景）。

## 7. 怎么迭代

1. 写完先 `python pipeline/preview.py out/<编号> 1`（每秒一格，十几秒出图），看 `out/<编号>/preview.jpg`；拿不准的时刻用 `--at 3.2 3.4` 只抽那几帧。页面报错会直接打印。
2. 满意了再出片（`tools/redo.py` 或 `make.py --reuse-voice`）。运动检查报"缺新动作"时，看报出的时间减去场景开头（`timeline.json` 的 `cuts`）落在哪个场景的第几秒，在那里加一拍（`beats`、新元素入场、整块换色），然后 `python pipeline/scene_check.py out/<编号> <场景序号>` 只渲染这个场景复查。小元素的小动作（一行字变色、一个小块滑一下、标签页切换）不算"新动作"，要有占画面一定面积的变化；在深色窗口里推近 4% 也可能不够，要配合整块换色或大元素入场。这七条里最常见的缺口是：场景开头只有标题在动、长句中段画面在等配音、揭晓前的铺垫段。
3. 出片后看 `review.jpg`，按第 2、3 节逐格对照，改到满意。

## 8. 踩过的坑

- **不能用** CSS `animation`/`transition`、`requestAnimationFrame`、`Math.random`、`Date.now()`：渲染是逐帧 `seek(t)` 截图。随机用 `MO.hash(i,seed)`。
- 3D 翻转（`rotateY` + `backface-visibility`）期间，父元素不能有 `filter` 或小于 1 的 `opacity`，否则 3D 被拍平、背面露出来。翻转要等进场模糊结束（约 0.42 秒后）再开始。
- 不用 emoji：Windows 和渲染机字体不同，可能显示成方块。图标用内联 SVG。
- 上屏文字全部来自剧本场景字段，不在代码里硬写（剧本检查要能扫到）。skill 未输入时，自动化一侧不能出现具体数字，"复购 3 次"要写成"老客复购"。
- 堆叠类动画先算最多同时有几个元素，确认最底下一个不压到标题和字幕条。
- 飞行中的元素终点要落在目标容器里面，不要掉出容器下沿。
- 场景时长由配音决定（`H.dur`），动画时间点要按 `H.dur` 或 `H.at` 算，不要假设固定时长。
- **元素 id 不能重复**，尤其不能叫 `st` `bg` `fx`（那是 KIT 三层的 id）。重复了会互相覆盖动画，引擎现在会直接报错。
- 企鹅站位（`mascot` 的 `x` `f` `S`）要和本场景的印章、标题、按钮错开；默认右下角，左下角有内容时改 `x`。
- 印章、标题这种大字放在企鹅的另一侧；评论框和关注按钮在左半边（`ctaBlock` 默认就是）。
- 闪白（`K.flash`）只用白色或很淡的颜色；整屏染成橙色看起来像出错。
- **配图不要用 `<img>` 垫在 `K.layers` 底下**：KIT 的背景画布是不透明的，会把它盖住。把图放进一个 `display:none` 的 `<img>`，再传给背景参数：`K.frame(id,t,H,{...BG,img:$(id+'img'),imgAlpha:0.7})`（背景画布自己画，还带慢推）。
- **`sfx` 只拿到 `sc`，拿不到 `H`**：要按配音卡点时，在 `init` 里存 `sc._H=H`，`sfx:sc=>[[sc._H.at(sc,'词')??默认秒,'pop']]`（`init` 比音效表先算）。
- 有实录帧的场景，引擎会等帧加载完再跑 `init`，所以 `init` 里可以用 `H.frame(sc,0)` 判断有没有实录；用了实录要把"示意"角标藏掉。
